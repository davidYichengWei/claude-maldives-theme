# Features

One file per thing the backdrop does. Each has the same four parts: its
sub-features, how a person gets to it in the app, how to drive it with
`verify/run.sh`, and the gotchas found so far.

| File | Feature |
| --- | --- |
| [trip-fetch.md](trip-fetch.md) | the lead boat comes for Clawd when a turn starts |
| [trip-land.md](trip-land.md) | the boat brings Clawd home when the turn ends |
| [island-day.md](island-day.md) | Clawd's day on the island and `/maldives island` |
| [waiting-signals.md](waiting-signals.md) | flag, lamp and hailing while the agent waits or fails |
| [fleet.md](fleet.md) | crew and shell boats, edges and wakes |
| [fireworks.md](fireworks.md) | fireworks on a push or MR |
| [day-night.md](day-night.md) | light and dark schemes |
| [wildlife.md](wildlife.md) | reef, whale shark, shoals, heron, hermit crab, night glow |
